REST API 수동시험 · 간편 실행

공통 확장과 동시 실행

DATEX·REST API·TCP/Binary·Kafka는 표준적합성시험 웹 연결 확장 하나를 사용합니다. 진행 중인 시험을 마친 뒤 기존 REST 확장을 새로고침하고, 이전 DATEX 전용 확장은 꺼 주세요. 새 시험 탭에서 사용합니다.

동시 시험마다 실행기 창과 별도의 시험 회차를 엽니다. 최대 16개 회차를 구분하고 같은 회차의 중복 제어를 막습니다. 충돌하는 로컬 포트는 설정 적용 시 변경값을 웹에 표시해 조정합니다.

공통 확장 사용 안내에서 갱신 및 새 PC 설치 순서를 확인하세요.

12개 시험 구성의 82개 상세항목을 하나씩 실행하고 직접 결과를 확인할 수 있습니다. 같은 PC의 상대 프로그램을 시험 대상으로 사용하며 Python은 포함되어 있습니다.

시험 한 항목 실행하기

  1. 시작하기.exe를 실행하고 시험 대상·정보를 선택합니다.
  2. 설정값을 확인합니다. ‘빈 포트 찾기’는 입력값만 바꾸며 아직 프로그램을 시작하지 않습니다.
  3. 상세시험 탭에서 확인할 항목을 선택합니다. 기본 선택은 한 항목입니다.
  4. ‘Chrome에서 웹 시험 열기’를 누르고, 웹의 ‘자체 시험 수행’에서 새 회차를 만듭니다. ‘Agent 접속 URL 복사’ 후 실행기에 붙여 넣습니다.
  5. ‘웹 환경설정 적용’을 누릅니다. 웹 입력값·체크박스·설정 요약을 확인합니다. 적용만으로 시험을 시작하지 않습니다.
  6. 웹의 ‘시험 시작’ 또는 실행기의 ‘웹에서 시험 시작’을 누릅니다. 역할에 맞춰 상대 프로그램이 준비됩니다.
  7. 완료 후 ‘웹 결과 보기’에서 매 회차 요청·응답과 판정 근거를 확인합니다. 확인했으면 ‘결과 확인 완료 표시’를 누릅니다.
  8. ‘다음 항목’을 선택하고 웹에서 새 회차를 만들어 반복합니다.

자료 조건을 구분하세요

조건준비와 선택
정상 자료 · 요청 오류정상 자료를 준비합니다. 정상 제공, 잘못된 요청, 인증·경로 오류를 함께 선택할 수 있습니다.
자료 부재 오류같은 유효 API에 자료가 없는 상태를 준비합니다. 제공 대상에서는 준비 확인란이 선택되어야 합니다.
빈 정상응답빈 정상 응답의 추가 검증입니다. 자료 부재 오류시험과 다릅니다.

제공시험의 ‘묶음 선택’에서 조건을 고릅니다. 정상 제공·자료 부재 오류·빈 정상응답을 한 회차에 섞지 않습니다. 요청시험은 모든 응답 조건을 함께 선택할 수 있습니다.

설정을 바꿨을 때

실행기에서 값을 바꾸면 다시 적용하기 전 시작할 수 없습니다. 웹에서 직접 수정했다면 웹의 ‘설정’을 눌러 적용하세요. 상대 프로그램은 엔진이 실제로 수락한 반복수·조회변수·인증값·오류 조건을 사용합니다.

API 키·Bearer 토큰은 시험용 값입니다. 실제 기상청·UTIC 등 운영 서비스로 호출하지 않고, 같은 PC의 모의 대상에 연결합니다.

기록과 종료

각 회차는 runs의 새 폴더에 보존됩니다. ‘상세 진단(고급)’에서 엔진·상대 기록과 적용 설정을 확인할 수 있습니다. 설정 파일에는 사용한 시험용 인증값이 들어갈 수 있으므로 공유 범위를 확인하세요.

자동 성공·실패와 ‘직접 확인’ 표시는 별개입니다. COMPLETE를 사용하지 않으며 엔진의 최종 결과와 전체 종료를 확인합니다. 중지 또는 창 닫기는 이 실행기가 시작한 프로그램만 정리합니다.

연결 확장이 응답하지 않으면 설치 상태를 확인하고 새 자체 시험 탭을 여세요. 이미 사용한 회차 URL은 재사용하지 않습니다. 포트 사용 중 안내가 나오면 빈 포트를 찾아 설정을 다시 적용하세요.

공통 시험 기록 보기

시험 안내 → 준비 → 진행 → 송신·수신 → 판정 근거 → 결과의 순서로 기록합니다. 목적·기준·실제 자료·확인 범위를 함께 확인하세요. 시험 기록 보기는 사용자용 결과를 열며, 내부 실행 정보와 파일은 상세 진단(고급)에서 확인합니다. 자동 판정과 직접 확인 완료 표시는 별개입니다.

협의한 조건으로 상세시험을 선택합니다

정상·오류 케이스는 각각 선택할 수 있습니다. 해당 항목의 입력 조건과 기대 HTTP·업무 응답을 확인한 뒤 협의한 항목만 실행하세요. 명세에서 정한 입력·응답과 명세 미정 부분에 적용한 시험 기준을 구분합니다.

요청 대상 시험은 대상의 유효한 요청과 시험기의 응답 전송을 자동 확인합니다. 대상 내부의 파싱·업무 처리·거부까지 직접 확인한 결과로 해석하지 않습니다. 정상 자료·자료 부재·빈 정상응답의 준비 조건은 서로 구분합니다.
