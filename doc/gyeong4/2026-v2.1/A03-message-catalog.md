# A03 부속 — 메시지·OID 대조 사전

관련 업무: **GM-64 / A03**. [인터페이스](A02-interface-scope.md) · [요구사항 해석](A03-requirements.md).

`OID-*`는 제3장 목록의 출처값, `R-M*`는 제4장 상세표의 출처값이다. 둘 중 한쪽을 자동으로 정답으로 선택하지 않는다. 원문에 적힌 기술 식별자·주기만 정리하고 전문 예제를 전재하지 않았다. 모든 OID는 생략 없이 표기한다.
