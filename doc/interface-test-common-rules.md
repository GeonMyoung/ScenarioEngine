# 인터페이스 시험 공통 규칙

- 시험 시나리오는 시험대상과 상대 역할, 시험 항목과 회차를 구분한다.
- 사용자 로그는 실제 송수신 순서, 원문, 관측값, 판정 기준을 보존한다. 접속 자격정보와 내부 진단은 별도 관리한다.
- 전체 결과와 로그를 전달한 뒤 MainScenario FINISH를 한 번 보낸다. 시험별 성공·실패·중지 상태를 유지한다.
- BSM 발행의 자동 성공은 발행 절차 완료다. 대상 수신과 최종 합격은 상대 수신 로그와 송신 기록을 대조한다.
- MQTT QoS는 0이다. BSM 발행 간격은 1초다. 수신 시험은 구독 후 목표 건수 또는 사용자 중지까지 기다린다.
- TIM의 유형은 furtherInfoID와 ITIS 조합으로 판별한다. content 형식은 수신 기록에 표시하며 합불 기준에서 제외한다.
