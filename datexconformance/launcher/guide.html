웹에 설정하고, 웹에서 시험을 시작하세요.

공통 확장과 동시 실행

DATEX·REST API·TCP/Binary·Kafka는 표준적합성시험 웹 연결 확장 하나를 사용합니다. 진행 중인 시험을 마친 뒤 기존 REST 확장을 새로고침하고, 이전 DATEX 전용 확장은 꺼 주세요. 새 시험 탭에서 사용합니다.

동시 시험마다 실행기 창과 별도의 시험 회차를 엽니다. 최대 16개 회차를 구분하고 같은 회차의 중복 제어를 막습니다. 충돌하는 로컬 포트는 설정 적용 시 변경값을 웹에 표시해 조정합니다.

공통 확장 사용 안내에서 갱신 및 새 PC 설치 순서를 확인하세요.

기존 실행기 창을 닫고 ZIP을 모두 압축 해제한 뒤 시작하기.exe를 더블클릭하세요. 같은 PC의 에뮬레이터를 시험 대상으로 사용합니다.

  1. 시험 환경설정 입력
    상단에서 시험을 고르고 왼쪽 ‘시험 환경설정’에서 개시요청 사용 여부와 도메인·포트·인증정보·시간을 확인하거나 수정합니다. 개시요청을 선택하면 정보제공 측의 Initiate 이후 정보요청 측이 Login을 보내며, 해제하면 일반 Login부터 시작합니다. 개시요청을 선택하면 ISO Server가 TCP에 접속하고 ISO Client가 수신 대기합니다. 해제하면 ISO Client가 접속합니다. 선택한 방향의 IP·포트 입력칸을 사용합니다. ‘상세시험 선택’ 탭에서 하나·일부·전체 항목을 고릅니다.
  2. 새 시험 주소 붙여넣기
    ‘Chrome에서 웹 시험 열기’ → 웹에서 ‘자체 시험 수행’ → ‘Agent 접속 URL 복사’ → 간편 실행 화면의 ‘붙여넣기’를 누릅니다.
  3. 환경설정 적용
    ‘웹 환경설정 적용’을 누릅니다. Chrome의 해당 시험 화면에 입력값과 선택 항목이 표시되고 실제 ‘설정’ 버튼이 눌립니다. 웹이 저장한 설정이 Agent에 전달됩니다. 이 단계에서는 시험을 시작하지 않습니다.
  4. 시험 시작
    웹의 설정 요약을 확인한 뒤 웹의 ‘시험 시작’ 또는 실행기의 ‘웹에서 시험 시작’을 누릅니다. 이때 에뮬레이터를 준비하고 실제 송수신 시험을 시작합니다. 완료되면 ‘웹 결과 보기’를 누르세요.

입력 편의 기능

기본값 채우기에뮬레이터용 기본값을 입력칸에 채웁니다. 확인·수정할 수 있으며, 채우는 것만으로 적용되지는 않습니다.
빈 포트 찾기사용 가능한 포트를 입력칸에 넣습니다. 직접 번호를 입력해도 됩니다.
에뮬레이터 설정같은 값을 반복 입력하지 않습니다. 입력한 도메인을 반대로 연결하고 인증정보·시간·포트를 맞춥니다.
적용 후 수정설정이나 선택 항목을 바꾸면 시작 버튼이 비활성화됩니다. 다시 ‘웹 환경설정 적용’을 누르세요. 웹에서 직접 수정하고 설정 버튼을 눌러도 실행기가 새 값을 확인합니다.
연결 해제시험 시작 전 연결을 끝낼 수 있습니다. 다음 연결은 새 회차 주소를 사용합니다.

하나씩 검증할 때

웹 결과에서 아래 내용을 확인한 뒤 ‘결과 확인 완료 표시’ → ‘다음 항목’을 누르세요. 다음 시험은 웹에서 새 회차를 열어 주소를 다시 복사합니다. 사용했던 주소는 재사용하지 않습니다.

  • 선택한 상세시험만 실행됐는지, 시험 대상과 송수신 방향이 맞는지
  • Login·인증·정보요청·발행·응답·취소 등 해당 절차의 메시지가 모두 보이는지
  • 메시지에 첨부된 실제 연계정보와 디코딩 결과가 보이는지
  • 기대 응답과 실제 응답, 시간 조건, 최종 성공·실패 사유가 연결되어 설명되는지

‘성공’은 자동 판정이고, ‘확인 완료’는 직접 결과를 살펴봤다는 표시입니다. 확인 표시는 플랫폼 판정을 바꾸거나 사후 증적을 제출하는 기능이 아닙니다. 확인 이력은 프로그램을 닫아도 남습니다.

필요한 항목만, 또는 전체 실행하기

하나항목을 클릭하고 ‘선택 행만’을 누릅니다.
일부원하는 항목의 체크박스만 선택합니다.
전체‘전체 선택’을 누릅니다. 표준 시간 조건을 유지하므로 수 분 이상 걸릴 수 있습니다.
TIM 복수 정보정보제공 측의 TIM 시험을 선택하면 ‘TIM 한 번에 2건 수신도 확인’ 옵션을 사용할 수 있습니다.
중지‘중지’를 누르면 이번 실행을 정리합니다. 수집한 기록은 삭제하지 않습니다.

진행이 안 될 때

시험 시작이 비활성상세시험을 선택하고 환경설정을 적용하세요. 수정한 값이 있다면 다시 적용합니다.
시험 구성이 다름선택한 시험과 같은 웹 시험의 ‘자체 시험 수행’을 새로 열어주세요.
이미 사용한 주소새 회차의 주소를 복사하세요. 이전 결과는 보존됩니다.
포트 사용 중‘빈 포트 찾기’로 다른 포트를 선택하고 새 회차에서 적용·시작하세요.
연결 실패Chrome에서 플랫폼 접속 상태를 확인하세요. 오류가 반복되면 ‘상세 진단(고급)’의 기록을 전달해주세요.
적용 조건과 기록 위치

시험 시작은 적용 완료된 입력값을 사용합니다. 시작 버튼이 저장 설정을 다시 불러오거나 입력한 포트를 바꾸지 않습니다. 기본 시간 값은 v9와 같으며 수정하면 입력값을 사용합니다. 실장비 연결은 기존 수동 안내서의 범위입니다.

실행별 기록은 runs에 저장됩니다. ‘상세 진단(고급)’에서 적용 설정, 최종 JSON, 전체 송수신과 연계정보를 열 수 있습니다. 폴더를 지우면 직접 확인 이력도 사라집니다. ZIP 배포본에는 과거 결과와 회차 주소를 넣지 않습니다.

웹 로그인은 Chrome에서 진행합니다. 입력창의 계정·비밀번호는 DATEX 시험용 인증정보입니다. 종료 시에는 이번 실행기가 시작한 엔진과 에뮬레이터만 정리합니다.

시험 안내 → 준비 → 진행 → 송신·수신 → 판정 근거 → 결과의 순서로 기록합니다. 목적·기준·실제 자료·확인 범위를 함께 확인하세요. 시험 기록 보기는 사용자용 결과를 열며, 내부 실행 정보와 파일은 상세 진단(고급)에서 확인합니다. 자동 판정과 직접 확인 완료 표시는 별개입니다.
